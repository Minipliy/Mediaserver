Vor dem ersten Start

Dein Server.
In deiner Hand.

Die App ist der Player. Deine eigene Serverinstallation liefert die Medien.

Neu hier? Die Schritt-für-Schritt-Anleitung erklärt die komplette Einrichtung mit einem Raspberry Pi, auch ohne Vorkenntnisse. Der Server ist kostenlos und offen auf GitHub.

1. Was du benötigst

  • Ein iPhone oder iPad mit iOS/iPadOS 17 oder neuer.
  • Einen Server mit kompatibler Mediaserver-API und Zugriff auf deine Medien. Die Serversoftware gibt es kostenlos auf GitHub; ein Raspberry Pi mit SSD ist eine gute Grundlage (Anleitung).
  • Eine HTTPS-Adresse mit gültigem Zertifikat und das vom Serverbetreiber vergebene API-Token.
  • Für Streaming eine Netzwerkverbindung; unterwegs zusätzlich ausreichenden Upload am Serverstandort.
Die App enthält keine Medien, stellt keinen Cloud-Speicher bereit und richtet keine Server-Hardware automatisch ein. Allgemeine NAS-, Plex-, Jellyfin- oder DLNA-Zugänge sind keine kompatible Mediaserver-API.

2. Medien auf dem Server ablegen

Kopiere deine eigenen Dateien mit einer eingerichteten Netzwerkfreigabe auf den Server, zum Beispiel im Finder über SMB. Die App selbst ist zum Durchsuchen, Abspielen und Herunterladen gedacht.

  • Musik/Interpret/Album/Titel.m4a
  • Filme/Mein Film.mp4
  • Serien/Serienname/Staffel 01/S01E01.mp4

Musiktitel, Alben und Interpreten werden soweit vorhanden aus den Audio-Tags gelesen. Nutze nur Inhalte, für deren Nutzung du die erforderlichen Rechte hast.

3. App verbinden

  1. Lade Mediaserver im App Store und öffne die App.
  2. Trage die vollständige HTTPS-Serveradresse ein, die dir dein Serverbetreiber gegeben hat.
  3. Gib das API-Token ein und tippe auf „Verbinden“.
  4. Erlaube den lokalen Netzwerkzugriff, wenn dein Server im Heimnetz liegt.

Die Verbindungsdaten werden im Schlüsselbund gespeichert. Unter „Server“ kannst du die Bibliothek neu einlesen lassen oder die Verbindung entfernen.

4. Streaming und Offline-Wiedergabe

Öffne einen Titel oder ein Video zum Abspielen. Über das Aktionsmenü kannst du Dateien herunterladen. Warte, bis die Datei im Tab „Downloads“ vollständig angezeigt wird, bevor du offline gehst.

Unter „Server → Downloads über Mobilfunk“ kannst du Mobilfunk für neue Downloads erlauben. Dein Mobilfunkanbieter kann dafür Datenvolumen berechnen.

5. Kompatibilität und Aufbereitung

Eine erkannte Dateiendung garantiert noch keine Wiedergabe. Entscheidend sind Container, Video- und Audiocodecs sowie dein Gerät. Für inkompatible Dateien kann der Server vorab eine MP4- oder M4A-Wiedergabekopie bereitstellen. Die Originale bleiben erhalten.

Server-Software und technische Einrichtung

Die zu dieser App gehörende Server-Software wird separat eingerichtet. Wenn du noch keinen kompatiblen Server betreibst, kontaktiere den Support zur Bereitstellung und Einrichtung der passenden Software. Kaufe nicht allein für die App neue Hardware, bevor die Kompatibilität geklärt ist.
